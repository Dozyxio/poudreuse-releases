# Poudreuse

Il neige sur votre bureau Windows.

Téléchargez `Poudreuse.exe` dans la [dernière version](https://github.com/Dozyxio/poudreuse-releases/releases/latest). L'application se met ensuite à jour toute seule.

Chaque version publie `SHA256SUMS.txt` : `Get-FileHash Poudreuse.exe` doit donner la même empreinte.
